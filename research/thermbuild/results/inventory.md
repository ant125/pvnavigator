# ThermBuild — dataset inventory

Read-only inspection of the local Fordatis download under `research/thermbuild/raw/`.
Raw zips were not extracted, converted, or gap-filled. No representative profiles
were built. Production code was not modified.

Supporting numbers: `inspection_summary.json` (generated by
`research/thermbuild/scripts/inspect_dataset.py`).

## Dataset structure

```text
research/thermbuild/raw/
  ThermBuild_measure_raw.zip
    ├── …_BSE1_…_wetReal_raw.csv      # TwinHouse O5 (western), 83 columns
    └── …_BSE2_…_wetReal_raw.csv      # TwinHouse N2 (eastern), 83 columns
  ThermBuild_measure_Temp_raw.zip
    ├── …_BSE1_…_wetReal_roomTemp.csv # 35 columns (no child2 MRT)
    └── …_BSE2_…_wetReal_roomTemp.csv # 36 columns (includes child2 MRT)

research/thermbuild/processed/        # empty (this phase)
research/thermbuild/scripts/inspect_dataset.py
research/thermbuild/results/          # this inventory + figures
```

There is **no separate metadata file**. Building parameters are encoded in the
filename (paper Table 2). All measure files share the **same 83-column layout**.
BSE1 still has DHW and solar columns; they are **all NaN** because those systems
are not installed.

Room-temperature files are **not** in the simulated schema. They add air
temperature at 10 / 110 / 170 cm and 10 cm below ceiling (`minus_10_AT`) plus
mean radiant temperature (`110_MRT`) per room.

## Measurement years and duration

Paper campaign: **7 February 2025 – 30 April 2026** (~15 months).

Local files:

| | BSE1 O5 | BSE2 N2 |
| --- | ---: | ---: |
| Rows | 42,528 | 42,483 |
| `consecutive_days` | 1 → 444 | 1 → 444 |
| Unique days | 444 | 444 |
| Complete 96-sample days | **442** | **442** |
| First day samples | 94 (partial start) | 49 (partial start) |
| Last day samples | 2 | 2 |
| First `day_of_the_year` | 38 (7 Feb) | 38 |
| Last `day_of_the_year` | 116 | 116 |
| Inferred last calendar date | **26 Apr 2026** | **26 Apr 2026** |

The last date in the files is **26 April 2026**, not 30 April 2026 as in the
abstract. Interior days are complete 24 h blocks (96 × 15 min). Internal gaps
are **NaN in columns**, not dropped rows.

This is **not** a Jan–Dec calendar year and is **not** aligned to PVNavigator’s
35,040-step non-leap production grid without a later mapping step.

## Sampling interval

**15 minutes.**

- `TIME` increments by **1** every row (unique step = 1.0).
- Paper Table 3 lists `TIME` unit as **hours**. Local files contradict that:
  `TIME` is an integer **sample index**, not hours and not Unix time.
- No clock-time column and no timezone column.
- Site is Holzkirchen (Europe/Berlin). Acquisition: Beckhoff PLC at 1 s,
  aggregated to 15 min; iDM heat-pump logger as fallback (paper §2.1).

## Available timestamps

| Column | Meaning |
| --- | --- |
| `TIME` | Monotonic 15-min index (0 … N−1) |
| `consecutive_days` | Campaign day 1 … 444 |
| `day_of_the_year` | 1 … 365 (38 at start, 116 at end) |

Room-temp files use `TIME` starting at **1** (measure files start at **0**) with
the same row count. Align by **row index**, not by the `TIME` value.

## Available metadata

Encoded **only** in filenames + the descriptor paper. No JSON/YAML catalogue.

Decoded for both local files (paper Table 2, `*` = TwinHouse as-built):

| Token | Value | Meaning |
| --- | --- | --- |
| `age1` | 2020 | GEG-refurbished envelope (TwinHouse current state) |
| `Use1001` / `Use1002` | Occdem profiles 1001 / 1002 | Simulated occupancy (not real residents) |
| `setB0` | no night setback | Paper: 20 °C all rooms; observed `Tset` is not constant 20 °C |
| `masshea` | heavy | Brick + concrete TwinHouse construction |
| `size100` | 100% | **140 m²** living area (German SFH average in the paper) |
| `SoProt0` | standard triple glazing | Not solar-protection glass |
| `roo3` | 7 common rooms | Plus unheated corridor / stairs / doorway |
| `BSE1` / `BSE2` | two HVAC packages | See `metadata_summary.md` |
| `vent1_155` | mechanical ventilation | **155 m³/h** (GEG design airflow) |
| `rot000` | 0° | Living room facing south |
| `wetReal` | real Holzkirchen weather | Institute weather station, not Meteonorm |

**Not in the files:** household electricity meter, PV, battery, EV, occupants as
people, cadastral address, construction year of the heat pump beyond the iDM
product names in the paper.
